# Completed Fix Reports

Store English reports of implemented and validated fixes in this directory. Do not place proposals or unimplemented changes here.

Name reports `YYYY-MM-DD-HHmmss-problem-slug.md`, using the completion time in KST (UTC+09:00). Follow the [fix tracking workflow and report requirements](../fix.md#completion-report-requirements).

Each report must link back to its original request in `../fix/`, document the actual source changes and validation results, and be linked from the corresponding row in [Fix Tracking](../fix.md).
